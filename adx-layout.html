Usage Guidelines

HTML Structure
<div class="adx-layout">
  <nav class="adx-topbar">...</nav>
  <div class="adx-wrapper">
    <nav class="adx-side-nav adx-side-nav--open">...</nav>
    <div class="adx-main-wrapper">
      <main class="adx-main">
        <section class="adx-section">
          <div class="adx-content-l">
            <!-- Your content here -->
          </div>
        </section>
      </main>
      <footer class="adx-footer">
        <section class="adx-section">
          <div class="adx-content-l">...</div>
        </section>
      </footer>
    </div>
  </div>
</div>
Rules from Figma
  • Never use margin — only padding and gap to space content
  • Footer is outside <main> to allow 100vh main content
  • Content wrapper tag should match content type (div, article, etc.)
  • Navigation pattern changes at phone breakpoint (side nav hidden)
  • Padding and gap for a given class will change across breakpoints
  • Use semantic HTML tags (<nav>, <main>, <section>, <footer>) for accessibility
