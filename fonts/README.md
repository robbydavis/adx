# Fonts Directory

This directory contains the brand font families for the Almanac DX UI Kit.

## Font Families

### Trade Gothic
Place all Trade Gothic `.otf` files in the `trade-gothic/` directory.

### Rift
Place all Rift `.otf` files in the `rift/` directory.

## File Format
All font files should be in `.otf` (OpenType Font) format.
